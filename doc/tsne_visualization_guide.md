## 二、图怎么看？（核心知识）

### 2.1 t-SNE 是什么

t-SNE 将高维向量（768d、128d、896d）**降维到 2D 平面**的算法。每个商品的高维嵌入 → 一个 2D 坐标点。坐标轴本身**没有物理含义**（不是 x=价格 y=销量），只表示"嵌入空间中的相对远近关系"。

### 2.2 图中的元素

| 元素 | 含义 |
|:----|:-----|
| 🔴 **红点** | **Head 商品**（最流行 20%，交互次数最多） |
| 🟠 **橙点** | **Mid 商品**（中间 60%） |
| 🔵 **蓝点** | **Tail 商品**（低频 20%，冷启动物品） |
| 点的距离 | 嵌入空间中的余弦相似度：距离近 → 向量相似；距离远 → 向量不同 |

### 2.3 横纵坐标轴

- **没有单位，没有标签**
- 只反映**相对位置**，不反映绝对数值
- 每次 t-SNE 运行结果都可能不同（但随机种子固定为 42，可复现）

## 三、什么算"好"？什么算"坏"？

### 3.1 好图的特征

| 特征 | 含义 | 图示 |
|:----|:-----|:-----|
| **有结构、有簇** | 嵌入空间把相似商品聚在一起 | 多个明显的点簇 |
| **颜色有区分度** | Head 和 Tail 在空间中的分布不同 | 红点和蓝点不完全混在一起 |
| **Fused 比 Content 更清晰** | 融合行为信号后结构变好了 | Fused 图的簇比 Content 图更分明 |

### 3.2 坏图的特征

| 特征 | 含义 | 图示 |
|:----|:-----|:-----|
| **一团糊** | 所有点均匀分布，无结构 | 像随机噪声 |
| **颜色均匀混合** | 高频/低频商品在整个空间均匀散布 | 红蓝点完全重叠 |
| **Fused 和 Content 一模一样** | 行为嵌入没起作用 | 两张图几乎相同 |

### 3.3 具体指标依据

t-SNE 图本身是定性的，需要结合以下定量指标交叉验证：

```python
# 运行时会输出的范数统计：
Content   norm: mean=9.31, std=7.58    ← 内容嵌入的分布范围
Behavior  norm: mean=0.68, std=0.53    ← 行为嵌入（小得多！）
Fused     norm: mean=29.81, std=0.14   ← 融合后（LN+Concat）
```

**重点关注：**
1. **Behavior norm 远小于 Content norm** → 不改 LN 会被淹没（验证了 LN 的必要性）
2. **Fused 的 std 很小** → LN 后所有向量被拉到近似的长度，这是预期的
3. **Fused 的 mean 大** → 融合空间的整体结构变化大，说明行为信号确实改变了空间布局

## 四、三张图对比看什么？

对每个数据集，需要**三张图一起看**：

```
Content 图          Behavior 图         Fused 图
(item_emb)        (behavior_emb)    (fused_item_emb)
    |                    |                 |
 文本语义           行为共现           两者融合
    |                    |                 |
 768/4096d           128d             896/4224d
```

### 4.1 Content vs Behavior（基线对比）

| 对比维度 | Content 图 | Behavior 图 |
|:--------|:----------|:-----------|
| 数据来源 | Sentence-T5 文本编码 | PPMI+SVD 共现矩阵 |
| 语义含义 | 商品文本描述相似度 | 用户行为共现模式 |
| 典型结构 | 按文本类别分簇（如"护肤品"簇） | 按行为模式分簇（如"经常被一起买"的簇） |
| 预期差异 | 文本近似的商品靠近 | 行为相关的商品靠近 |

### 4.2 Fused 图（核心关注）

Fused 图应该展示**前两者的优点结合**：

- ✅ **好情况**：继承了 Content 的全局结构 + Behavior 的局部调整
- ⚠️ **一般**：和 Content 图差别不大（行为信号被淹没，说明 LN 没生效或行为信息弱）
- ✅ **好情况**：同一 Content 簇内的点按行为模式进一步细分（出现子簇）
- ❌ **坏情况**：结构比 Content 更乱（说明融合方式有问题）

### 4.3 流行度着色的含义

颜色（红/橙/蓝）显示的**不是嵌入本身的属性**，而是商品的**外部流行度标签**。好的融合空间应该：

- **高频商品（红）** 在空间中占据多个不同位置（说明同是高频，但属于不同品类/行为模式）
- **低频商品（蓝）** 应该靠近某个高频区域（说明冷启动物品被映射到行为相似的高频商品附近） → 这对**冷启动推荐**很关键
- 如果所有红点高度集中 → 高频商品被过度聚在一起 → 可能是嵌入维度不够或信号太单一

## 六、常见问题

### Q1：为什么每次跑出来的图不一样？

t-SNE 的初始化包含随机性。我们的代码固定了 `random_state=42`，所以**相同输入可以复现**。但如果改参数（`perplexity`、`n_iter`、`n_sample`），结果会有变化。**不是 bug，是 t-SNE 的特性。**

### Q2：采样 2000 个点够吗？

对于 12k~18k 个商品的数据集，2000 个采样（~15%）足够反映整体结构。如果需要更精细的局部结构，可以调大 `--n_sample`（但运行时间会增加 O(n²)）。

### Q3：perplexity=30 是啥？

Perplexity 是 t-SNE 最重要的超参数——它控制每个点看多少个邻居：
- **perplexity 小（5-10）**：关注局部结构，簇更小更多
- **perplexity 大（50-100）**：关注全局结构，簇更大更少
- **默认 30**：平衡局部和全局，适合大多数数据集

建议用不同 perplexity（10, 30, 50）各跑一次做对比实验。

### Q4：这些图和论文里的图有什么区别？

论文中的图通常会：
1. **使用 768d 版本**（主实验维度），当前 v1 用 4096d 只是参考
2. **加上标注**（标注典型商品的簇标签，如"sports shoes"、"board games"）
3. **左右对比**（Content vs Fused 放一起，用箭头标注变化区域）
4. **聚焦一个数据集**（通常选提升最大的 Sport）
