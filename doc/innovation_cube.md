## ⚠️ 第 0 条纪律：空格 ≠ 真空地

**二维矩阵里的空格，含义是「本轮审计没查到」，不是「领域里不存在」。**

本轮审计是**目标导向**的——全程只问「谁也在往 SID 里注入行为信号」。

## 4. ★ 跨界魔方：10 个候选

每条格式：**源领域 → 成熟方法 → 映射到 SID → 落在哪格 → 状态 → 你需要什么**

### 4.1 分布式系统 → 一致性哈希（Consistent Hashing）
- **成熟方法**：增删节点时只重映射 1/K 的键
- **映射**：码本扩容时，只改变 1/K 物品的 SID，其余**完全不变**
- **落格**：⑤ 码本动态更新 × 方法改进
- **状态**：🔴 未验证（DACT 用 drift 置信度，是启发式；**一致性哈希没人用**）
- **需要**：动态/时序数据（或模拟"新增物品流"）；纯 CPU 可做
- **可行性**：高（算法简单，可离线模拟）

### 4.2 图论 → 超图分割（Hypergraph Spectral Clustering）
- **成熟方法**：购物篮是**超边**（一次买 5 件 = 一条 5 元边），超图谱聚类
- **映射**：用超图谱划分**直接构造** SID 层次，替代 RQ-VAE
- **落格**：③ 多源融合 × 方法改进
- **状态**：🔴 未验证（MMGRec / OGR 用的都是**二部图**，超图未必有人做）
- **需要**：PyG 的超图模块；重建 RQ-VAE 管线
- **可行性**：中高

### 4.3 信息论 → 率失真理论（Rate–Distortion）
- **成熟方法**：R(D) 给出给定失真下的**最小码率**
- **映射**：给出「码本大小 K 的最优条件」—— FORGE 全是**经验扫参**（3×8192 vs 4×4096）
- **落格**：② 粒度 × 评估体系
- **状态**：🔴 未验证
- **需要**：**纯分析**，用已有 codes + 嵌入即可，**零 GPU**
- **可行性**：**最高**（成本最低，且是理论贡献）

### 4.4 NLP → BPE / Unigram LM 分词
- **成熟方法**：最优分词 = 最大化语料似然；BPE merge 准则
- **映射**：SID = **物品的分词**；用 BPE 的 merge 准则**自底向上**构造层次，替代 RQ-VAE 的**自顶向下贪心**
- **落格**：③ × 方法改进 + ② 粒度
- **状态**：🔴 未验证
- **需要**：重写 SID 构造（中等工程量）
- **可行性**：中

### 4.5 编码理论 → 最大距离码（Reed–Solomon / LDPC）
- **成熟方法**：保证码字间**最小汉明距离**
- **映射**：SID 碰撞消解 = 保证任意两物品的 SID **最小距离 ≥ d**
- **落格**：① 唯一性 × 方法改进
- **状态**：🟡 部分（ECM/RRS 是**贪心**放松 nearest-centroid；**用编码理论构造**未见）
- **需要**：重写碰撞消解模块
- **可行性**：中

### 4.6 生物信息 → 层次聚类树（UPGMA / Neighbor-Joining）
- **成熟方法**：从距离矩阵构造**系统发生树**
- **映射**：SID 层次 = 物品的**系统发生树**；树深 = SID 层数
- **落格**：② 粒度 × 方法改进
- **状态**：🔴 未验证
- **需要**：距离矩阵（你有行为 + 内容两个）；scipy 即可
- **可行性**：中高（scipy 现成）

### 4.7 推荐系统内部 → 序列位置编码 / 层序约束
- **成熟方法**：Transformer 位置编码；层次结构中的**单调性约束**
- **映射**：RQ-VAE 的层次**没有显式约束** L0 必须比 L1 更泛化；可加**层序单调性正则**
- **落格**：③ × 方法改进
- **状态**：🔴 未验证
- **需要**：改 RQ-VAE 损失；你已有 trainer
- **可行性**：中高

### 4.8 统计力学 → 相变 / 临界现象
- **成熟方法**：序参量、临界点、标度律
- **映射**：**码本崩塌是否是一个相变**？临界点在哪？
- **落格**：③ × 评估体系
- **状态**：⚫ 部分已试（你的 E1 塌缩诊断 62/256 是这个方向的经验版，但**没有理论刻画**）
- **需要**：多 seed × 多配置的塌缩数据
- **可行性**：中

### 4.9 因果推断 → 后门调整 / do-calculus
- **成熟方法**：分离"因果效应"与"混杂效应"
- **映射**：行为信号的增益里，有多少是**流行度混杂**带来的？
- **落格**：③ × 评估体系
- **状态**：🟡 部分（MMGRec 的 popularity token 隐约相关）
- **需要**：设计干预实验（打乱流行度但保留共现）
- **可行性**：中（但理论要求高）

### 4.10 运筹学 → 最优运输 / Sinkhorn
- **成熟方法**：Sinkhorn 迭代解熵正则 OT
- **映射**：SID 分配 = 物品到码字的**运输问题**
- **落格**：③ × 方法改进
- **状态**：⚫ **已试过**（你的 SF-RQ 方向，gate 0 过但伤 z → 已并入稳健性叙事，见 memory `session-2026-09-09`）
- **可行性**：❌ **不要重开**
