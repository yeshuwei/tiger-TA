# 创新点二候选方向：Semantic ID 行为结构质量评估

## 1. 实验目的

验证一个最小假设：

> **Semantic ID经过量化后是否保留了原始行为结构，可以作为衡量Semantic ID质量的一个指标。**

本实验只做可行性验证，不立即设计新的筛选算法或自适应方法。

---

## 2. 核心指标

### 2.1 Behavior Structure Retention

对每个物品 \(i\)，分别计算：

* \(N_B^K(i)\)：原始行为结构空间中的 Top-K 邻居；
* \(N_Q^K(i)\)：RQ-VAE量化后连续表示 \(x_i^q\) 的 Top-K 邻居。

定义：

$$
BSR@K=
\frac{1}{|I|}
\sum_{i\in I}
\frac{|N_B^K(i)\cap N_Q^K(i)|}{K}
$$

取：

$$
K\in\{10,20\}
$$

使用 \(x_q\) 而不是 Semantic ID 的整数 token 计算相似度。

---

## 3. 只使用已有实验结果

不新增 T5 训练。

直接使用当前已有的 7 个表示：

1. TIGER / Content Only
2. Zero Transition
3. Random Transition
4. Shuffled Transition
5. Raw-CoOcc
6. ItemCF
7. TA-SID

每种方法已有 RQ-VAE 输出，因此只需要计算其量化后的表示并进行邻居比较。

---

## 4. 最小实验流程

### Step 1：获得原始行为结构

使用已有的 PPMI+SVD 行为表示：

$$
e_i^b
$$

计算 item-item cosine similarity，得到：

$$
N_B^{10}(i),\quad N_B^{20}(i)
$$

---

### Step 2：获得量化后的表示

对每种 Semantic ID 方法，取得 RQ-VAE 最终量化表示：

$$
x_i^q
$$

计算 cosine similarity，得到：

$$
N_Q^{10}(i),\quad N_Q^{20}(i)
$$

---

### Step 3：计算 BSR

得到：

| Method    | BSR@10 | BSR@20 | NDCG@20 | Recall@20 |
| --------- | -----: | -----: | ------: | --------: |
| TIGER     |        |        |      已有 |        已有 |
| Zero      |        |        |      已有 |        已有 |
| Random    |        |        |      已有 |        已有 |
| Shuffled  |        |        |      已有 |        已有 |
| Raw-CoOcc |        |        |      已有 |        已有 |
| ItemCF    |        |        |      已有 |        已有 |
| TA-SID    |        |        |      已有 |        已有 |

## 5. 只检查三个问题

### Q1：BSR能否区分真实结构和随机结构？

重点比较：

$$
TA\text{-}SID,\ Raw\text{-}CoOcc
$$

与：

$$
Random,\ Shuffled
$$

如果 Random / Shuffled 也得到很高 BSR，则该指标失去意义。

---

### Q2：BSR是否与推荐效果具有一致关系？

比较：

$$
BSR \leftrightarrow NDCG@20
$$

以及：

$$
BSR \leftrightarrow Recall@20
$$

在 Beauty、Sport、Toys 三个数据集上计算 Spearman 相关系数。

这里只需要看**方向和稳定性**，不需要复杂统计分析。

---

### Q3：BSR是否只是“SID唯一性”的替代指标？

额外计算一个简单指标：

$$
Uniqueness=
\frac{\#Unique(SID)}{\#Items}
$$

检查：

$$
BSR \leftrightarrow Uniqueness
$$

如果 BSR 与唯一性高度重合，则说明 BSR提供不了独立信息。

---

## 6. Go / No-Go

### GO

同时满足以下基本条件：

1. Random / Shuffled 的 BSR明显低于真实行为结构方法；
2. 三个数据集上 BSR 与 NDCG@20 / Recall@20 整体呈正向关系；
3. BSR不是简单由 SID uniqueness 决定；
4. TA-SID的行为结构保持能力与其推荐性能提升具有一致性。

满足后，再考虑把它发展为：

> **Behavior-Structure-Aware Semantic ID Quality Assessment**

进一步设计 Semantic ID 筛选。

---

### NO-GO

出现以下任一情况即可停止：

* Random / Shuffled 也能获得高 BSR；
* 不同数据集上的 BSR 与推荐性能关系方向相反；
* BSR基本等价于 SID uniqueness；
* TA-SID推荐效果明显提升，但 BSR没有对应变化。

此时不再继续设计“创新点二”，将 BSR 作为第五章的辅助分析或直接放弃。

---

## 7. 本轮明确不做

本轮**全部不做**：

* 不训练新的 T5；
* 不设计新的 loss；
* 不做自适应 K0；
* 不做阈值学习；
* 不做多阶段筛选；
* 不比较大量新的行为表示；
* 不做新的数据集扩展；
* 不做复杂理论证明。

### 最终目标

只用现有 Semantic ID + 现有推荐结果，完成：

$$
\boxed{
\text{行为结构}
\rightarrow
\text{量化后结构保持}
\rightarrow
\text{推荐性能}
}
$$

这条关系能否成立。

**如果成立，再考虑把它发展成第二个方法模块；如果不成立，立即止损。**
