# E49 行为空间诊断（RQ-VAE 之前，GPU-free）

指标定义：
- `freq_leak` = Spearman(||behavior_emb||, log1p(item freq))，越高＝越被流行度主导
- `pc1_cos_freq` = |cos(第一主方向, 归一化流行度方向)|
- `eff_rank` = exp(entropy(σ²/Σσ²))，越低＝谱越集中
- `top1_energy` = σ₁²/Σσ²
- `cons_auc` = P(cos(序列相邻对) > cos(随机对))，0.5 = 随机；作用在 RQ-VAE 之前的 behavior 向量上；**对 itemcf 系统性偏高**（相邻对是整篮对的子集，属定义优势，不可单独引用）
- `cons_auc_local` = P(cos(序列相邻对) > cos(同篮非相邻对))，0.5 = 不区分；**关键判据**：行为空间是否区分「局部序列上下文」与「泛共现」
