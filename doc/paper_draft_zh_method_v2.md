# 4 Method: TA-SID

## 4.1 Preliminary: Semantic ID based Generative Retrieval

**问题设定。** 令 $\mathcal{I}$ 为去重后的商品集合（$|\mathcal{I}|=N$），每个用户 $u$ 的交互序列为按时间排序的商品列表 $S_u=[i_1,\dots,i_{L_u}]$。顺序推荐的目标是：给定历史 $S_u^{<t}=[i_1,\dots,i_{t-1}]$，预测用户下一步交互的商品 $i_t$。

**语义 ID。** 生成式检索（如 TIGER）先把每个商品 $i$ 量化成一个离散的**语义 ID（Semantic ID）** $c_i$——一个由 $L$ 个 token 组成的短码 $c_i=[c_i^1,\dots,c_i^L]$——得到一个可逆的映射 $\Phi: \mathcal{I}\to\mathcal{Z}$ 与其逆 $\Phi^{-1}: \mathcal{Z}\to\mathcal{I}$。量化在这里扮演"建索引"的角色：连续的商品表示被离散化为索引码，商品的相似性由码的距离近似。

**生成式检索。** 有了 $\Phi$，推荐被重写为两个子问题：

1. **编码**：把用户历史 $S_u^{<t}$ 映射为 ID 序列 $[c_{i_1},\dots,c_{i_{t-1}}]$；
2. **生成**：用序列模型自回归地预测下一商品的 ID $c_{i_t}$，即建模 $p(c_{i_t}\mid c_{i_1},\dots,c_{i_{t-1}})$。

与在连续嵌入空间做内积打分的双塔范式不同，这一框架把推荐看作**序列到序列的 token 生成**：可以直接复用语言模型的架构与训练技巧；束搜索（beam search）天然产出多样化的 top-$k$ 候选；预测的是商品本身而非近似最近邻的嵌入，从而规避了表示空间退化与 ANN 近似的误差。语义 ID 的分层结构（见 4.4.2）还让单个 token 携带粗到细的语义粒度。

本节只陈述该范式的抽象形式；语义 ID 如何从商品表示中构造是 4.4 的主题，TA-SID 对范式本身不作出任何修改。

## 4.2 Overview of TA-SID

**核心论点。** 现有生成式推荐器（TIGER）从**纯内容嵌入**构造语义 ID：商品的 SID 编码"这个商品是什么"（内容语义），却不编码"用户在行为上会怎样消费它"（转移结构）。后者——例如"运动服之后常买蛋白粉"——是与内容正交的协同信号，决定了下一个交互而非下一个相似商品。TA-SID（Transition-Augmented Semantic IDs）在 SID 生成阶段引入一个独立的**商品转移通道**，使最终 SID 同时编码内容语义与转移结构，从而提升下游生成式检索的质量。

**流水线。** 如图 1 所示，TA-SID 由三个模块构成：

1. **转移动力学建模**（§4.3）：从训练行为序列构造商品-商品转移图，经 PPMI 加权与截断 SVD，得到 128 维转移行为嵌入 $e_i^b$；
2. **转移增强的 SID 生成**（§4.4）：把内容嵌入 $e_i^c\in\mathbb{R}^{768}$ 与行为嵌入 $e_i^b\in\mathbb{R}^{128}$ 分别做 Layer Normalization 后拼接为融合嵌入 $\tilde e_i\in\mathbb{R}^{896}$，送入 RQ-VAE 量化为 4-token 的 SID $c_i$；
3. **生成式检索**（§4.5）：以用户历史的 SID 序列为输入，训练 T5 自回归预测目标 SID，解码经逆映射 $\Phi^{-1}$ 得到商品候选。

**即插即用。** 除 RQ-VAE 的输入嵌入从"纯内容"换成"内容⊕转移"外，RQ-VAE 与 T5 的结构、训练代码与超参数均与 TIGER 完全一致。整个转移通道（§4.3）不含任何可训练参数，融合（§4.4.1）亦为静态操作——TA-SID 的可学习部分完全沿用 TIGER。

## 4.3 Transition Dynamics Modeling

**动机。** 内容嵌入刻画"语义相似"：两件白色 T 恤内容上几乎相同，但用户很少连续消费它们；而"羽绒服 → 围巾"内容上并不相似，却在购物序列中稳定共现。顺序推荐要预测的是**转移**，不是相似。因此我们显式地从行为序列中提取商品间的转移结构，并把结果作为与内容互补的信号注入 SID 生成。我们的建模选择是：用**窗口共现 + 谱嵌入**刻画转移结构——与内容编码器正交（无参、纯统计）、可独立复现。

### 4.3.1 Item Transition Graph Construction

**共现图。** 从训练序列 $\{S_u\}$ 构造无向加权商品图 $G=(\mathcal{I},\mathcal{E})$。对每条序列，用滑动窗口 $w=3$（当前商品左右各 1 个邻居）统计窗口内商品的两两共现次数，得到对称共现矩阵 $C\in\mathbb{R}^{N\times N}$，$C(i,j)$ 为商品 $i$ 与 $j$ 在窗口内共同出现的次数（$i\neq j$）。保留计数不低于阈值 `min_cooccur=1` 的边，构成稀疏图。

需要说明的是：我们取的是**无向共现**而非有向转移概率。理由有二：一是无向统计天然对称，便于后续谱分解；二是我们关心的不是"i 直接流向 j"的单步概率，而是"i 与 j 共享转移上下文"的**结构等价性**（见 4.3.2），后者用对称统计更稳健。

**PPMI 加权。** 高频商品（畅销品）与任意商品都有共现，其边缺乏判别力。为此我们对 $C$ 施加**正点互信息（PPMI）**变换：

$$\mathrm{PPMI}(i,j)=\max\left(\log\frac{C(i,j)\cdot\Sigma}{\left(\sum_{j'}C(i,j')\right)\left(\sum_{i'}C(i',j)\right)},\;0\right),\quad \Sigma=\sum_{i,j}C(i,j)$$

PPMI 对仅在小范围特定上下文中共现的商品对保留强权重，对高频平庸共现降权至零；这是语言模型中度量词关联的标准做法。加权后的矩阵 $\mathrm{PPMI}$ 即转移图 $G$ 的邻接权重。

### 4.3.2 Transition Behavior Representation

对 PPMI 矩阵做**截断 SVD**，取前 $k=128$ 个奇异方向：

$$\mathrm{PPMI}\approx U_k S_k V_k^\top,\qquad E_b=U_k S_k^{1/2}\in\mathbb{R}^{N\times k}$$

商品 $i$ 的转移行为嵌入为 $E_b$ 的第 $i$ 行 $e_i^b$。

**为什么有效。** 由于 PPMI 对称，$U_k\approx V_k$，于是 $E_b E_b^\top = U_k S_k U_k^\top\approx\mathrm{PPMI}$：两个行为嵌入的内积近似重建它们的 PPMI 权重。而 PPMI 权重高 ⟺ 两个商品共享相似的转移上下文（与同一批商品共同出现）。因此**行为嵌入的余弦相似度量的是结构等价——共享转移模式的程度——而非直接共现**：两个从未同时出现、但各自与相同的第三方商品共同出现的商品，也会在行为空间中被拉近。实测验证了这一性质：行为空间近邻商品余弦相似度可达 0.58，而二者直接共现计数为 0，仅共享 2–4 个共同邻居。这一性质使行为嵌入捕捉二阶转移结构，恰是 content 信号缺失的部分。

**冷启动处理。** 训练序列中未出现的商品（冷启动商品）在图中无任何边，其行为嵌入被显式置零，等价于转移通道对它们不可用、退化为纯内容 SID。该处理在实现层面保证了融合的数值一致性（见 4.4.1）。

**非学习性质。** 转移行为嵌入是纯统计、零可训练参数的谱嵌入，不依赖任何模型训练，可从序列统计独立复现，并与下游 RQ-VAE/T5 完全解耦。

## 4.4 Transition-Augmented Semantic ID Generation

给定内容嵌入 $e_i^c$ 与转移行为嵌入 $e_i^b$，本节回答两个问题：**如何融合**（4.4.1）与**如何量化**（4.4.2），使转移信号真正进入码本决策，从而让 SID 同时编码两种语义。

### 4.4.1 Multi-source Representation Fusion

直接拼接并不可行：$e_i^c$（Sentence-T5-base，768 维）与 $e_i^b$（SVD 输出，128 维）在数值尺度上不匹配，前者会从数值上淹没后者，RQ-VAE 几乎无法利用转移通道。因此我们对两个模态**分别做 Layer Normalization**，再拼接：

$$\tilde e_i=\left[\ \mathrm{LN}_c(e_i^c)\;\|\;\mathrm{LN}_b(e_i^b)\ \right]\in\mathbb{R}^{896}$$

**为什么用 Concat 而非 Add。** Add 把两种模态压进同一低维子空间求和，转移信号会被内容主导而退化；Concat 保留两条**独立的信息通道**，让 RQ-VAE 的码本可以分别（或交叉地）编码内容与转移信息。对 896 维整体做单个 LN 同样不可取——它会混合两种模态的统计量，破坏通道独立性。

**为什么不做更复杂的融合。** 我们的主张是"简单即有效"：LN+Concat 是零学习参数的静态融合，没有引入任何可学习组件，训练代码与 TIGER 完全一致。相比之下，为融合多源行为信号引入动态路由、专家网络等手段会显著增加复杂度（并带来新的训练负担）。§7 的消融从反面验证了该设计的必要性：注入死维度（ZeroPad）后性能与纯内容基线持平——**维度增加不是提升来源**；注入打乱配对的转移向量（Shuffled）后性能反而下降——**错误的结构信号是有害的**；唯有真实的转移结构带来一致的正向提升。

### 4.4.2 Semantic ID Quantization

**RQ-VAE。** 融合嵌入 $\tilde e_i$ 送入 RQ-VAE 量化为 SID。编码器为 MLP $\tilde e_i \xrightarrow{896\to512\to256\to128\to64} z_i\in\mathbb{R}^{32}$，得到低维隐向量后由**残差向量量化器（RVQ）**逐层量化：

$$q_k=\arg\min_{c\in\mathcal{C}_k}\|r_{k-1}-c\|_2,\qquad r_k=r_{k-1}-q_k,\qquad r_0=z_i$$

其中 $\mathcal{C}_k$ 为第 $k$ 层码本（$k=1,2,3$，每层 256 个码字，$e$-dim$=32$）：第 1 层量化 $z_i$，第 2 层量化残差，第 3 层量化残差的残差，重构 $\hat z_i=q_1+q_2+q_3$，解码器 MLP 重建 $\hat{\tilde e_i}$。残差结构使越靠前的码字携带越粗粒度的语义。

**训练损失。** 总损失为重建项 + 量化项 + 承诺项：

$$\mathcal{L}=\|\tilde e_i-\hat{\tilde e}_i\|_2^2+\sum_{k=1}^{3}\left[\|\mathrm{sg}(z_k)-q_k\|_2^2+\beta\,\|z_k-\mathrm{sg}(q_k)\|_2^2\right]$$

其中 $\mathrm{sg}(\cdot)$ 为 stop-gradient，$\beta=0.25$；第 3 层量化使用 Sinkhorn 熵正则（$\epsilon=0.003$）软分配，促进码本均衡利用，避免码字坍缩。

**碰撞消解。** 码本组合空间（$256^3\approx 1.6\times10^7$）远大于商品数，但 RQ 码字并非均匀使用，不同商品仍可能被量化到同一码（碰撞）。商品数与码空间比例越接近，碰撞越不可避免；碰撞直接破坏映射 $\Phi$ 的可逆性。因此：对共享同一码的商品子集，用 Sinkhorn 软分配（`use_sk=True`）**重新量化以推离**，迭代至多 30 轮；仍无法区分的商品追加一个**碰撞位** token（0/1/…）保证唯一。最终每个商品的 SID 为 4 个 token（3 码本级 + 1 碰撞位），经偏移 $c+k\cdot256+1$ 映射为词表 token（$k$ 为级号），词表大小为 $4\times256+1=1025$（含 pad）。SID 的逐商品唯一性保证了 $\Phi^{-1}$ 是良定义的——这是生成式检索正确性的前提。

**为什么 SID 因此"转移增强"。** RQ-VAE 的码本聚类作用于融合嵌入：两个商品被聚到同一 SID 的邻域，需要它们的**内容与转移两个通道**同时相近。因此 SID 之间的距离同时反映内容相似与转移结构相似——这正是 TA-SID 相比 content-only SID 的本质区别。§7 的转移一致性（AUC）实验在量化空间 $x_q$ 上验证了该行为：转移对相似度显著高于随机对（AUC 0.869–0.962），且全面高于纯内容 SID。

## 4.5 Generative Retrieval with TA-SID

**序列化。** 训练/推理时，用户历史 $S_u^{<t}$ 中的每个商品经 $\Phi$ 映射为其 4-token SID，展开为 token 序列输入 T5；目标为下一商品 $i_t$ 的 4-token SID。历史按商品数左填充至 `max_len=20`（即 80 个 token）。

**训练。** T5 以标准 teacher forcing 方式在标签位移后的目标 SID token 上最小化交叉熵（配置见 §5）。需要强调的是，**TA-SID 对 T5 不做任何改动**：网络结构、目标函数、超参数与 TIGER 一致，T5 只负责在给定的 SID 词汇上做序列预测。

**推理与检索。** 推理时，给定历史 SID 序列，以**束搜索**（beam size 30）生成 30 个候选的目标 SID；每个候选经逆映射 $\Phi^{-1}$（商品→SID 的倒排索引）唯一对应一个商品，即得到 top-30 推荐候选。束搜索直接提供多样化的候选集合，无需额外的近邻检索结构。

**评估口径。** 由于 $\Phi^{-1}$ 是精确的，目标商品命中 ⟺ 其 SID 出现在 top-$k$ 束候选的 SID 序列中，因此 Recall@k / NDCG@k 可直接按 token 序列匹配计算，无需近似度量。

**与 TIGER 的关系。** 整个 §4.5 的检索机制与 TIGER 相同，TA-SID 与 TIGER 的唯一区别是**上游 SID 的生成**：TIGER 从纯内容嵌入量化 SID，TA-SID 从内容⊕转移的融合嵌入量化 SID。正是这一区别，使同样的生成式检索返回的不再只是内容相关的候选，而是**内容相关且转移一致**的候选——这是 §6 中一致提升的直接来源。
