# 4.6 Adaptive Transition-Preserving Quantization

## 4.6.1 Motivation: Fixed-Size Codebook Limitation

§4.4 中，融合嵌入 $\tilde e_i$ 经 RQ-VAE 量化为 SID，其中粗层（第一层）码本容量 $K_0$ 是固定超参——沿袭 TIGER 的默认值 $K_0=256$，对所有数据集一视同仁。本节指出这一固定容量假设的局限：**不同数据集的转移结构需要不同大小的粗层容量，固定 $K_0$ 必然在"容量不足"与"容量浪费"二者之一上失配。**

残差量化（RVQ）中，码字按层级携带由粗到细的语义：第 1 层码本决定量化对原始分布最主要的刻画，其规模 $K_0$ 直接决定首层能保留多少结构；第 2、3 层通过残差在已量化结构之上补细节。因此，**若 $K_0$ 不足，转移结构在首层即被压碎，后续残差层无法挽回**；而若 $K_0$ 过大，码字大量闲置，白白消耗表示空间与训练成本。

这一失配在数据间是真实的：我们在三数据集上以统一的 $K_0=256$ 训练 RQ-VAE 后发现，Beauty/Sport 的粗层码本使用健康（利用率 80%/97%）且量化近无损，而 **Toys 的粗层码本坍缩到仅用 62/256 个码字（利用率 24%）**，转移结构发生显著丢失。把 $K_0$ 一律调大（如 1024）对 Beauty/Sport 是纯浪费，不放任 Toys 却又不修 Tooys 的塌缩。这驱动我们提出自适应机制：让 $K_0$ 由数据决定，而不是手工拍一个全局常数。

## 4.6.2 Transition Preservation Diagnosis

**度量：转移一致性 AUC 与 z-gap。** 要诊断量化是否保留了转移结构，需要一个与推荐性能解耦、直接在量化空间可算的信号。沿用 §5.5 的转移一致性指标：设商品 $i$ 的重建表示 $x_i=\sum_{l} \mathrm{codebook}_l[c_i^{(l)}]$（各层码本向量之和），转移一致性 AUC 定义为
$$\mathrm{AUC}=\mathbb{P}\big(\cos(x_a,x_b)>\cos(x_{a'},x_{b'})\big),\quad (a,b)\sim\text{转移对},\ (a',b')\sim\text{随机对},$$
其中转移对取自训练序列的相邻共现（与 §4.3.1 转移图同源，无泄漏）。AUC 高 ⟺ 量化空间保留了"转移对比随机对更相似"的结构。

在此基础上定义**量化转移损失 z-gap**：
$$z\text{-gap}=\mathrm{AUC}(z)-\mathrm{AUC}(x_q^{\text{full}}),$$
即编码器输出 $z$ 空间（未量化的转移结构上限）与全量化重建 $x_q$ 空间之间的 AUC 差距。$z$-gap ≈ 0 表示量化近无损，转移结构被完整保留；$z$-gap 大表示量化丢弃了结构。**$z$-gap 是本节诊断与自适应机制的核心信号。**

**三数据集画像（$K_0=256$）。**

| Dataset | z AUC | xq[full] AUC | **z-gap** | L0 用码(util) |
|:--|--:|--:|--:|--:|
| Beauty | 0.8677 | 0.8676 | **0.0001** | 204/256 (80%) |
| Sport | 0.9646 | 0.9614 | **0.0032** | 249/256 (97%) |
| Toys | 0.9656 | 0.8724 | **0.0931** ⚠ | 62/256 (24%) |

三个发现：

**（1）问题真实存在（E1）。** Toys 是唯一粗层码本坍缩的数据集（62/256 码），也是唯一 $z\to x_q$ 大丢的数据集（z-gap=0.093，即 9.3% 的转移结构被量化丢弃）。粗层码本利用率与转移损失之间呈现一致的对应。

**（2）根因是码本分配，不是"容量本身不够"（E2）。** 在编码器输出 $z$ 上做无训练的 post-hoc k-means 扫描（$k=64$–8192）发现：$k=8192$ 时转移 AUC 接近 $z$（0.964 vs 0.965），说明 $z$ 空间包含的结构只需足够多的簇即可保留；而真实 RQ-VAE 在 L0 只用了 62 个码，其转移 AUC（0.854）甚至低于 fresh $k=64$ 的 k-means（0.933）。**问题出在 RQ-VAE 的训练分配把容量浪费在了少数码字上，而非 256 个码本质上不够。**

**（3）机制验证：扩容而非强制均衡（E3）。** 对 Toys 重训 RQ-VAE，两种修复思路对比：Sinkhorn 均衡正则（A）修复了利用率，但碰撞率上升、重建变差、$z$ 空间退化——不可取；把粗层容量扩到 $K_0=1024$（B）则同时恢复转移 AUC（0.872→0.963）、降低碰撞、保持重建质量。**证实恢复转移结构的机制是容量分配（allocation），而非对固定码本的强制均匀化。**

**负面结果：转移熵不能预测容量需求。** 一个看似自然的候选信号是行为层的转移熵 $H(B\mid A)=\sum_a P(a)\sum_b P(b\mid a)\log_2 P(b\mid a)$（转移分布的不可预测性）：直觉上"转移越复杂、需要的容量越大"。实测推翻了这个直觉——三数据集加权条件熵为 Beauty 3.77 / Sport 3.88 / Toys 3.52 bits，**转移熵最低的 Toys 恰恰最需要扩容**，方向完全相反。原因在于 $H(B\mid A)$ 度量行为层的多样性，而容量需求由 $z$ 空间的簇结构与 encoder 的分配行为决定（E1/E2 已证明 Toys 的问题是码本分配）。因此转移熵不能作为免训练的预测器，论文如实报告该反例。

## 4.6.3 Adaptive K0 Selection

综合诊断，我们提出**基于 z-gap 的反馈闭环**来自适应地选择粗层容量：

```
输入: 数据 D、item embeddings E、容差 ε = 0.01
输出: 粗层容量 K0*(D)
──────────────────────────────────────────────
1  K0 ← 256                    # 细层固定 K1=K2=256
2  repeat
3    训练 RQ-VAE(D; K0, 256, 256)     # 仅粗层可变
4    生成 SID → 重建 x_q[full]
5    z-gap ← AUC(z) − AUC(x_q[full])  # 转移结构量化损失
6    if z-gap ≤ ε: break        # 近无损,容量充足
7    K0 ← 2·K0                  # 按需扩容重训
8  返回 K0* = K0
──────────────────────────────────────────────
```

**为什么是"自适应"而非 grid search。** 三点本质区别：

- **有准则。** 终止条件由 lossless 定义（$z$-gap ≤ ε，即相对 $z$ 天花板损失 <1%），不是"扫若干候选挑指标最好"。
- **按需触发。** 仅在 $z$-gap 超阈值时扩容；对已无损的数据（Beauty/Sport）零额外训练。
- **结果因数据而异。** 三数据集自动落在 $\{256,256,512\}$：Beauty/Sport 保持 256，Toys 一次扩容到 512 即达标，而非统一的最优超参。

**执行结果。**

| Dataset | K0* | z-gap@256 | z-gap(K0*) | 扩容次数 |
|:--|:--|--:|--:|--:|
| Beauty | 256 | 0.0001 | 0.0001 | 0 |
| Sport | 256 | 0.0032 | 0.0032 | 0 |
| Toys | **512** | 0.0931 | 0.0045 | 1 |

Toys 经一次扩容后 $z$-gap 从 0.093 降到 0.0045（低于阈值 0.01），转移结构被恢复。这验证了自适应机制的核心属性：**仅在需要的数据上付出恰好需要的容量**。

**三态洞察。** 统一的视角把数据集刻画为三种状态，单一固定 $K_0$ 无法同时满足三者，自适应机制的正确行为是仅在"不足态"扩容至 lossless：
- **容量充足态**（Sport）：$z$ 高（0.965）+ 利用率高（97%）+ gap≈0 → 256 恰好够；
- **结构受限态**（Beauty）：$z$ 低（0.87）+ gap≈0 但扩容无收益（对 $k$ 不敏感）→ 扩容无意义；
- **容量不足态**（Toys）：$z$ 高 + 粗层坍缩（24%）+ gap 大 + 扩容有收益 → 必须扩容。

## 4.6.4 Complexity Analysis

**RQ-VAE 训练成本。** 基线（TIGER/TA-SID）本身需每数据集训练一次 RQ-VAE。自适应机制的额外成本是**至多 $\lceil\log_2(K_0^*/256)\rceil$ 次扩容重训**：
- Beauty/Sport：0 次额外训练（$K_0^*=256$，直接复用现有模型）；
- Toys：1 次额外训练（$256\to 512$），且该次训练同时产出最终模型，不存在"白训"。

与 grid search 对比：grid search 扫 $M$ 个候选需 $M$ 次训练（如 $\{256,512,1024\}$ 即 3 次），自适应机制在最坏情况下至多 $\log_2$ 次数（本例实际仅 1 次），且**每一次训练都有明确的决策角色**（要么达标终止，要么推进扩容），不存在被舍弃的候选。对已无损的数据集成本恒为 0，这是 grid search 不具备的性质。

**T5 侧成本。** Beauty/Sport 因 $K_0^*=256$，其 T5 模型与主实验完全复用，**零新增生成式训练**；Toys 因 $K_0^*=512$ 需要以新 SID 重训 T5，并追加一个 $K_0=1024$ 的固定大容量对照（§5.6）。T5 侧新增的生成式训练总量 = 2 个配置 × 3 seed（见 §5.6.3），是自适应机制的增量成本。

**推理与存储成本。** $K_0$ 增大只影响 RQ-VAE 码本行数（256→512/1024），码字维度不变（$e$-dim=32），故量化推理的 FLOPs 不变、码本内存增幅可忽略（<100 KB 级）；SID 仍为 4 token（3 码本级 + 1 碰撞位），T5 的词表与推理复杂度完全不变。**自适应机制在推荐侧不引入任何额外开销。**

**综合。** 自适应机制的总增量 = 至多 1 次 RQ-VAE 重训 +（仅对需扩容的数据）2 配置 T5 训练；换来的是被固定容量牺牲的转移结构恢复（Toys z-gap 0.093→0.0045）以及由此带来的推荐提升（§5.6.3）。收益-成本权衡在 §5.6 给出量化验证。
