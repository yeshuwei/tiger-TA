## §0 结论摘要（先答"实验是否有效 / 有无异常"）

### 实验是否有效：**有效**

| 判据 | 结果 |
|:--|:--|
| 36 格（3 数据集 × 3 seed × 4 epoch）全部产出 | ✅ 36/36 |
| 本次轨迹 = 既有已发表 run 的同一条轨迹 | ✅ **12/12 逐位相同**（`torch.equal`，max_abs_diff = 0.000000） |
| CSV 的 loss 可回溯到训练日志 | ✅ **36/36 与日志同 epoch 行逐位一致** |
| 控制变量（唯一自变量 = epoch） | ✅ pair sampling 每数据集只构造一次并跨 seed/epoch 复用；超参由 `main.parse_args` 逐字复用 |
| 产物隔离 | ✅ `rqvae/ckpt/` 与 `data/` 在实验开始后 **0 个文件被改动** |

**关键有效性的含义**：`epoch=50` 的 traj checkpoint 与既有 `best_loss_model.pth` 逐位相同（9/9 个 tag；其中 `Toys_TA_SID_768d` 的**两个**重复 run 目录都比对了），
独立复现了 `doc/checkpoint_selection_behavior_auc_summary.md` 的核心发现——**既有 `best_loss` 臂全部冻结在 epoch 49**。
本次 4 个 epoch 点是这条真实轨迹上的点，不是"另训了一次"。

### 异常：**有 2 处，均已知且已量化，不改变结论**

1. **主口径 z-gap 混有 Sinkhorn 缓解代价**（方案已预告的混淆）。
   codegen 末层带 `sk_epsilons=[0, 0, 0.003]` 缓解；碰撞率高的 epoch 缓解力度大，把"缓解代价"计入了 z-gap。
   差异集中在 ep50：Toys/2024 主口径 **+0.0326** vs 原生口径 **+0.0140**（差 2.3 倍），且该格 prefix-3 碰撞率 5.06%，而收敛区 27 格仅 0.00000–0.00193。
   收敛区两者一致到 ~0.0002。⇒ **§4 的判定对两个口径分别报，不让主口径单独承担结论。**
   附带的数据质量列 `codes_L0_agree_native` = **1.0（36/36）**，说明码文件与 CPU 原生 L0 完全一致；差异全部来自 L1/L2 层，与"只缓解最后一层"的设定自洽。
2. **`epoch=50` 与其余三点不是同一 regime**。ep50 处于欠训练 + 码本近塌缩状态：
   L0 utilization 0.059–0.309（收敛后 0.461–0.957）、prefix-3 碰撞 0.00486–0.05057（收敛后 0.00000–0.00193）、AUC(z) 0.841–0.950（收敛后 0.946–0.978）。
   ⇒ **把 4 个点当一条趋势线拟合会把 regime 切换误读成趋势**，故 §4 同时报"含 ep50"与"仅收敛区"两种口径。

## §4 关键判断：`reconstruction loss ↓` 是否伴随 `z-gap ↑`？

**结论：不成立。这个现象不稳定，且 6/9 个 run 的趋势方向与假设相反。**

逐 run 的 Spearman ρ（`(−recon_loss, z_gap)`；因 recon 在 9/9 run 内严格单调降，此 ρ 等价于 `(epoch, z_gap)`）：

| 数据集 | seed | ρ 主口径 | ρ 原生口径 | 仅收敛区 ep500–2000 的 ρ（主 / 原生） | 收敛区 z-gap 极差 |
|:--|:--:|--:|--:|:--|--:|
| Beauty | 2024 | **+0.80** | **+1.00** | +0.5 / +1.0 | 0.0041 |
| Beauty | 2025 | +0.20 | +0.20 | −1.0 / −1.0 | 0.0011 |
| Beauty | 2026 | **+0.80** | **+0.80** | +0.5 / +0.5 | 0.0044 |
| Sport | 2024 | −0.20 | −0.20 | +1.0 / +1.0 | 0.0038 |
| Sport | 2025 | **−0.80** | **−0.80** | −0.5 / −0.5 | 0.0043 |
| Sport | 2026 | **−0.80** | **−0.80** | −0.5 / −0.5 | 0.0033 |
| Toys | 2024 | −0.40 | −0.40 | +0.5 / +0.5 | 0.0027 |
| Toys | 2025 | −0.40 | −0.40 | +0.5 / +0.5 | 0.0026 |
| Toys | 2026 | 0.00 | **+0.60** | +0.5 / +0.5 | 0.0009 |

**三点判定依据**（n = 4，只报方向不宣称显著性）：

1. **方向在数据集之间翻转。** Beauty 3/3 为正（ρ = +0.2 ~ +0.8，与假设一致）；Sport 3/3 为负（ρ = −0.2 ~ −0.8，与假设**相反**）；Toys 2/3 为负。
   ⇒ 假设至多在 **1 个数据集**上成立。
2. **负相关由 ep50 这一个 regime 点驱动，不是趋势。** ep50 的 z-gap 是全程最大的一格（Toys/2024 +0.0326、Toys/2025 +0.0139、Sport/2026 +0.0104），
   而它的 recon 也是全程最大（2.44–3.69）⇒ "recon 高 + z-gap 大"把 4 点回归拉成负斜率。
   一旦只看收敛区（ep500/1000/2000，此区谱内 recon 仍单调降 1.96→1.77 等），ρ 的符号在 seed 之间自相矛盾
   （Beauty +0.5/−1.0/+0.5；Sport +1.0/−0.5/−0.5；Toys 全 +0.5），而 z-gap 的**总变动幅度 ≤ 0.0044**。
   ⇒ **收敛区内不存在可复现的单调关系，只是噪声。**
3. **Toys/2026 的口径依赖暴露了不稳健。** 主口径 ρ = 0.00、原生口径 ρ = +0.60 ⇒ 同一 run 的趋势方向随"是否做 Sinkhorn 缓解"改变。
   一个稳健的现象不应如此。

**符合方案 §6 的处置**：方案写明"如果不存在，则不继续强行构造该方向"。据此，本实验**不建议**把
"behavior structure preservation during quantization" 作为第二个创新点继续推进。

**一个反向的正面观察（不是"gap 变大"，而是"两边一起变好"）**：
AUC(z) 与 AUC(xq) 在 9/9 run 内都随 epoch 上升（ρ(epoch, AUC(z)) = 0.2~1.0，多数 ≥ 0.8），
且 xq 的上升幅度跟得上 z（31/36 格 AUC(z) 仍略高）。**量化没有让结构保持变差，它和 z 一起改善；z-gap 始终被压在一个小量级内。**

## §5 结果是否跨 seed 稳定

**分两层看：AUC 层稳定，z-gap 层不稳定。**

* **AUC(z) / AUC(xq)：稳定。** 12 个（数据集 × epoch）格中，跨 3 seed 极差为 0.0024–0.0181；
  收敛区更小（Sport ep500–2000：0.0025–0.0069；Toys ep500–2000：0.0048–0.0076）。三点曲线的**形状**（ep50→ep500 大跳、之后平台）在 9/9 run 一致。
* **z-gap：不稳定。** 跨 seed 极差与该格 |均值| 之比：Beauty ep50 = **14.4×**（均值 −0.0006，极差 0.0091，符号都不同）、
  Sport ep2000 = **10.4×**（均值 +0.0005，极差 0.0055，seed 间正负翻转）、Sport ep500 = 5.2×。
  即使在较稳的格（Toys ep2000 = 0.38×）也只是量级小，而非一致。
* **符号一致性**：ep50 的 9 格 z-gap 为 `[-0.0046, -0.0018, +0.0045, +0.0059, +0.0069, +0.0094, +0.0104, +0.0139, +0.0326]`——
  两个负值都是 Beauty，**数据集内的符号一致性高于跨数据集**。

⇒ 可跨 seed 复现的是 **"AUC 双升、z-gap 量级很小"** 这个结构；
**不能**跨 seed 复现的是 z-gap 的具体数值、符号、或随 epoch 的方向。

| quant（ep2000） | 3.55–3.90 | **最高** 6.22–6.44 | 3.46–3.69 |
| AUC(z)（ep2000） | 0.960–0.971 | 0.958–0.965（最低） | **最高** 0.971–0.978 |
| ep50 z-gap | **−0.0046 ~ +0.0045**（唯一出现负值的数据集） | +0.0059 ~ +0.0104 | **+0.0069 ~ +0.0326**（最大） |
| 收敛区 z-gap 均值 | +0.0046 / +0.0074 / +0.0057 | −0.0002 / +0.0024 / +0.0005（最小） | +0.0050 / +0.0040 / +0.0057 |
| L0 util（ep2000） | 0.777–0.809 | **0.891–0.957** | 0.715–0.805 |
| ep50 L0 util | 0.172–0.219 | 0.234–0.309 | **0.059–0.301**（最低） |

要点：

1. **Beauty 是唯一让假设成立的集合**，也是唯一在 ep50 出现 z-gap 负值（AUC(xq) > AUC(z)）的集合。
   它的 recon 最低、AUC(z) 高但非最高、收敛区 z-gap 最大 ⇒ 与其它两个数据集**不共享同一模式**。
2. **Sport 是"难重建"的一端**：recon、quant 都最高，跨 seed 的 recon 极差也最大（0.0456–0.0551 vs Beauty 0.0135–0.0202、Toys 0.0059–0.0135），
   而它的收敛区 z-gap 最小（3 格均值 ≤ +0.0024，其中 2 格为负）。
3. **Toys 的信号几乎全部来自 ep50**：ep50 z-gap 最大（均值 +0.0178，跨 seed 极差 0.0257，超均值 1.4×），
   收敛后立刻掉到 +0.0022 ~ +0.0073 且三 seed 一致。**Toys/2024 ep50 的 L0 util = 0.059（256 个码只用 15 个）**，是本次最极端的一格。
4. **一个弱但方向一致的观察（仅 3 个点，不作为结论）**：收敛区里 recon 最高的数据集（Sport）z-gap 最小，
   recon 最低的（Toys/Beauty）z-gap 更大。这与"训练目标与结构保持偏离"的预期方向不符，
   更像是**难度/尺度效应**而非偏离效应。样本量 3，不据此推断。

## §7 局限与不应推出的结论

1. **主口径含 Sinkhorn 缓解代价**（§0 异常 1）。所有判定已在两个口径上分别核对；收敛区两者一致到 ~0.0002，
   差异只在 ep50 显著，故 §4 的"不成立"判定不是口径造成的。
2. **每 run 仅 4 个 epoch 点**，每个 ρ 只有 6 对样本，**不做显著性宣称**，只报方向与幅度。
   "仅收敛区"一列只有 3 个点（3 对），更弱，仅用于显示"去掉 ep50 后方向自相矛盾"。
3. **单一指标（cosine AUC，正 topk × 负 degmatch）**。CSV 另存了 `auc_*_topk_uniform` / `auc_*_all_degmatch` 两套备选口径但本文未展开；
   若换口径结论可能变化——本报告只对主口径负责。
4. **不解释机制、不宣称因果。** 本实验只观测"沿同一条轨迹取 4 个点"的共变，未做任何干预。
5. **不外推到其他 K0、其他码本规模、其他数据集。** 本次固定 `num_emb_list=[256,256,256]`、`e_dim=32`、3 层。
6. **不应推出的结论**：
   * ✗ "RQ-VAE 训练会损害行为结构保持"——数据不支持，AUC(z) 与 AUC(xq) 一同上升。
   * ✗ "ep50 的 z-gap 大 ⇒ 早期 checkpoint 结构保持差"——ep50 的 AUC(z) 本身就低（0.84–0.95），
     z-gap 大同时 AUC 两个绝对值都差，不能读作"保持得不好"。
   * ✗ "应该用更晚的 checkpoint"——本实验不比较 selection strategy（方案 §2 明确排除），
     且 z-gap 在收敛区没有趋势，无法由此推出取点建议。
7. **`epoch` 是分类位置而非等距时间轴**（50/500/1000/2000 在训练时间上不等距），图中按等距分类位置摆放并写明真实 epoch。
