# 5.5 Transition Preservation Analysis

主实验证明 TA-SID 提升推荐性能，但端到端性能无法直接回答机制问题：**提升是否因为 SID 真正编码了转移结构？** 本节从量化输出空间直接检验——若 TA-SID 的 SID 空间保留转移结构，则转移对在量化空间中应比非边对更相似。

## 5.5.1 转移一致性（Transition Consistency AUC）

设商品 $i$ 的 SID 为 $[c_i^{(1)},c_i^{(2)},c_i^{(3)},c_i^{(4)}]$，其量化表示重建为 $x_i=\sum_l \mathrm{codebook}_l[c_i^{(l)}]$（各层码本向量之和）。比较两类商品对的余弦相似度：

- **正样本（转移对）**：训练序列中相邻共现、共现频次 ≥ 2 的前 1000 个无向对（与 §4.3.1 转移图同源，无泄漏）；
- **负样本（度匹配非边）**：取与正样本端点处于同一度分桶（$\lfloor\log_2 \deg\rfloor$）的非边样本对 20,000 对，并剔除自环与转移图内已有边。

> **负采样口径说明。** 本节采用**度匹配负采样**，而非全量均匀随机采样，以降低节点流行度差异带来的结构预测偏差：均匀采样下负样本端点平均度数仅为正样本的约 1/9（Sport：20.2 vs 179.7），分类器可凭"热门商品彼此都相似"取得虚高分数；度匹配后该差距收窄至 Δ=−17.7。两种口径给出的变体**排序完全一致**（Spearman ρ 同为 0.9429），故结论不由该捷径支撑。

**AUC = P(转移对相似度 > 非边对相似度)**（Mann-Whitney U 统计量），0.5 表示转移关系未被编码，1 表示完美区分——这是链路预测评估关系编码能力的标准指标。

**表 5-2**：量化空间（$x_q^{[\mathrm{full}]}$）中转移关系的编码一致性。ΔAUC = 该行 − Content-only。AUC 在固定 RQ-VAE 量化空间上确定性计算，报告单值。

| Dataset | Method | **AUC** | ΔAUC |
|:--|:--|--:|--:|
| Beauty | **TA-SID** | **0.9560** | **+0.1195** |
| Beauty | Content-only | 0.8365 | — |
| Beauty | Shuffled（错配行为下界） | 0.7974 | −0.0391 |
| Sport | **TA-SID** | **0.9647** | **+0.0568** |
| Sport | Content-only | 0.9080 | — |
| Sport | Shuffled（错配行为下界） | 0.8763 | −0.0317 |
| Toys | **TA-SID** | **0.9651** | **+0.0900** |
| Toys | Content-only | 0.8751 | — |
| Toys | Shuffled（错配行为下界） | 0.8127 | −0.0624 |

**第一，转移关系被有效编码。** TA-SID 在三数据集上均为全部变体中 AUC 最高者（0.9560 / 0.9647 / 0.9651），相对 Content-only 的 ΔAUC 为 **+0.1195 / +0.0568 / +0.0900**，三个数据集方向一致。

**第二，两端稳健、中间分层。** 跨三个数据集稳定成立的是：**TA-SID 恒居首**，**Shuffled（错配行为）恒居末**，且 Shuffled **低于"完全不给行为"的 Content-only**（Δ = −0.0391 / −0.0317 / −0.0624）。中间变体（ItemCF / Raw-CoOcc / ZeroPad）的具体名次在数据集间并不完全一致，故本文只主张"两端 + 分层"，不主张逐名次同序。

**第三，为什么用 AUC 而非绝对相似度。** Content-only 的量化空间会把商品整体挤在一起，转移对与普通对的绝对余弦相似度**同时**被抬高，因此绝对相似度混入了"整体聚集度"这一与转移编码无关的量。**AUC 只关心"转移对相对普通对是否更相似"，剥离了聚集度干扰**——这与对比学习的 alignment-uniformity 框架一致。

> **诚实说明（口径与量级）。** 各数据集 ΔAUC 的**绝对量级**与主实验 NDCG@20 的提升幅度**不对应**（按 ΔAUC 为 Beauty > Toys > Sport，按 NDCG 提升为 Sport > Beauty > Toys）。跨数据集可迁移的是"**结构保留的层次与两端**"，而非具体名次或量级；本指标**不作跨数据集的绝对阈值**使用。
>
> **口径变更记录（2026-09-29）：** 本节原报告的 uniform 负采样口径数值（Beauty 0.869 / Sport 0.962 / Toys 0.872）**已废弃，勿引用**；主口径统一为上表的度匹配口径（Beauty 0.9560 / Sport 0.9647 / Toys 0.9651）。两套数值不可并列比较。

**第四，结论对转移对选择稳健（鲁棒性检验，探索性说明，可选入附录）。** 正样本为"共现频次 ≥ 2 的 top-1000"，其中 Toys 有近半数对仅共现 2 次（top-1000 中位共现 2 次、最高 27 次）——单对强度弱，需确认该结论不依赖这批弱对。以更高共现阈值（count ≥ 3 / ≥ 5）在同一批负样本（seed=0）上重算量化前后的一致性落差：

| Dataset | count ≥ 2 | count ≥ 3 | count ≥ 5 |
|:--|--:|--:|--:|
| Toys | 0.0931 | 0.0957 | 0.0804 |
| Beauty | 0.0001 | 0.0001 | 0.0001 |
| Sport | 0.0032 | 0.0032 | 0.0019 |

结论在全部阈值下保持：**Toys 的量化丢失约 8–10%（即使只保留共现 ≥ 5 次的最强 136 对），Beauty/Sport 仍近无损**。原因有二：（i）AUC 是群体统计量（Mann-Whitney U），测"转移对相似度分布整体高于负样本对"的概率，弱对只会把两个空间一起稀释、不会选择性抬高某一空间；（ii）该落差是同一批转移对在两个空间上的 AUC **差值**，转移对的绝对强度同时作用于编码器空间与量化空间、在差值中抵消。

## 5.5.2 Code Consistency（SID 码质量）

转移结构进入 SID 的前提是 SID 本身质量可靠：码字被有效利用、碰撞可消解、映射 $\Phi$ 可逆。量化码质量用两个指标刻画：

**（1）碰撞率（collision rate）**：共享同一 3-token 码、需碰撞位 token 区分的商品比例，直接反映映射 $\Phi$ 的可逆性受损程度。

**（2）码本利用率（utilization）**：各层实际使用的码字数 / 码本容量，反映码本是否被有效利用（而非坍缩到少数码字）。

**表 5-3**：三数据集 TA-SID 的 SID 码质量（$K_0=256$ 配置）。

| Dataset | items | 3-token 唯一向量 | 碰撞率 | L0 用码(util) |
|:--|--:|--:|--:|--:|
| Beauty | 12,101 | 12,095/12,101 | 0.05% | 204/256 (80%) |
| Sport | 18,357 | 18,357/18,357 | 0.00% | 249/256 (97%) |
| Toys | 11,924 | 11,889/11,924 | 0.29% | 62/256 (24%) ⚠ |

**第一，SID 近似逐商品唯一。** 三数据集碰撞率均 ≤ 0.29%，映射 $\Phi$ 与 $\Phi^{-1}$ 良定义，生成式检索正确性成立——这是 §5.4 中精确命中评测的前提。

**第二，Beauty/Sport 码本利用健康，Toys 粗层利用率偏低。** Beauty/Sport 的 L0 利用率 80%/97% 表示粗层容量得到有效利用；Toys 的 L0 仅用 62/256 码（24%）。

> ⚠ **2026-09-29 订正：** 该现象**不是**"Toys 容量不足"的触发信号，也**不**对应任何第二创新。E45/E47 已查明这是 TA-SID × Toys × seed2024 这一组合的单次初始化特例（同数据换 RQ-VAE 种子即恢复到 194/256，见 [e47_seed_health_isolation.md](e47_seed_health_isolation.md)），content-only 与 ZeroPad 各种子均正常，且健康 256 与 512 在推荐层无统计差异。**原文"固定容量 $K_0=256$ 在 Toys 上容量不足"的表述已作废。**
> 注：SID 码质量数据源于 §4.3 的量化流程；此处仅作 §5.5 转移保持分析的对照（SID 整体可靠），不做机制主张。

## 5.6.0 【已裁撤】原文（历史存档，勿引用）

§4.6 提出了自适应保转移量化（Adaptive Transition-Preserving Quantization）：粗层码本容量 $K_0$ 由数据通过 z-gap 反馈闭环自动决定。本节用三个层面的实验验证其有效性，回答三个问题：**Q1** 自适应是否恢复转移结构（SID 质量）；**Q2** 是否优于"直接把 $K_0$ 调大"的固定大容量；**Q3** 结构提升是否最终转化为推荐提升（T5）。

> 说明（写作素材，不进正式图注）：$K_0\in\{256,512,1024\}$ 为离散实验配置（Fixed-small / Adaptive / Fixed-large），纵轴半对数。$K_0=256$ 时 z-gap=0.093 远超无损阈值 ε=0.01（虚线），是唯一显著断崖；扩容到 512 即跌破 ε（0.0045）；继续扩到 1024（0.0003）已远低于 ε，无进一步结构收益——自适应规则（z-gap ≤ ε）恰在 512 收敛。图源：`doc/figures/paper_k0_sweep_curve.png`（`tools/plot_paper_k0_curve.py`）。

**第一，256 是唯一瓶颈。** $K_0=256$ 的 z-gap（0.093）比其他所有配置（≤0.0045）大 20 倍，粗层坍缩是唯一显著的结构损失来源；扩容到 512 后立即降到阈值（0.01）以下。

**第二，"越大越好"不成立。** AUC 在 512–2048 区间不单调（0.968→0.963→0.974），且随着 $K_0$ 增大利用率持续下降（60%→18%）。容量继续增大没有一致的结构收益，只是浪费码字。

**第三，最优区间 512–1024。** 512 以最小容量达到与更大容量相当甚至更好的 AUC（0.968）与重建（0.1414），是性价比冠军。**这直接论证了自适应机制"取满足条件的最小 $K_0$"的设计合理性。**
