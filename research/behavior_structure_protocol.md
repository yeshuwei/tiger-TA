## 1. 行为关系主参照：采用**去对角原始局部共现 C**（对原任务书的偏离，附理由）

### 1.1 冻结决议

| 角色 | 参照 | 说明 |
|:--|:--|:--|
| **主参照** | **去对角的原始局部共现矩阵 C** | 一切结构保持结论的分母 |
| 辅助参照 | **PPMI**（C 的变换） | 仅作稳健性检查 |
| 压缩后向量参照 | **SVD 行为嵌入** `behavior_emb*.parquet`（128d） | 表征层的压缩结果 |

### 1.2 对原任务书的调整与理由

**原任务书（`Behavior Structure Preservation Audit.md` §3）规定"行为关系主要参照：PPMI"。本协议改为 C 为主参。**

| # | 理由 |
|:--:|:--|
| R1 | **保持与既有证据可比**。项目现有主判据口径（E 图）**本来就是去对角 C**（`tools/behavior_structure_probe.py:164-165` 的 `setdiag(0)` + `eliminate_zeros`），54/54 路 AUC 与 `doc/ablation_main_table_3datasets.md` 全部建立在该口径上。改主参照会**静默作废既有证据链**。 |
| R2 | **PPMI 是 C 的破坏性变换**：`max(log(...), 0)` 截断 + 行/列归一化（`rqvae/build_transition_graph.py:126-145`）。负 PMI 被置 0 会把**弱边整体抹平**，使"结构在某一阶段丢失"的诊断**混入 PPMI 自身的截断效应**，无法归因。 |
| R3 | **C 是无参参照**，其"边是否存在 / 边有多重"直接可读；PPMI 引入全局频率归一化，与"流行度捷径"问题纠缠（见 §11-3）。 |
| R4 | **避免把同一参照的两种变换当成两条独立证据**（§1.4）。 |

### 1.3 统一规则（四条，全部钉死）

1. **共现窗口**：`window_size=3` ⇒ `half_window=1` ⇒ 仅**相邻对** `(s[i], s[i+1])`；**无向对称**（`(i,j)` 与 `(j,i)` 合并计数）；`min_cooccur=1`。
2. **序列口径**：只读 `data/{Ds}/train.parquet` 的 `history + [target]`（与行为向量构造一致，`rqvae/build_transition_graph.py:227-234`）。
   ⚠ **与既有 `top_transition_pairs` 不同**——后者只遍历 `history`、**丢弃 target**（`tools/sid_consistency_contrast.py:122-128`）。**本协议采用 `history+target` 为主口径**；`history`-only 降级为**敏感性口径**，若引用必须显式标注。
3. **物品集合**：以 `data/{Ds}/item_emb_768d.parquet` 的 `ItemID` 行序为准，共 `N` 行；矩阵形状 `(N, N)`。
4. **去对角**：`C.setdiag(0.0)` 后 `eliminate_zeros()`。
   ⚠ **必须记录的关键事实**：行为**向量**（`behavior_emb*.parquet`）是用**含对角**的 C 算的（`build_transition_graph.py:100-121` 无 `setdiag`），而**参照空间用的是去对角 C**。⇒ **向量空间与参照空间不是同一张矩阵**。这是已知的口径差，必须在所有报告中声明，不得当作"实现不一致"来修。

### 1.4 证据独立性声明（**强制**）

C 与 PPMI 是**同一矩阵 C 的两个函数**，二者的结构保持结果**高度相关**。

> **纪律**：C 与 PPMI 的结论**只能作为"同一参照的稳健性检查"成对报告**（"换 PPMI 后排序是否保持"），
> **禁止**在论文或任何汇总中把二者**并列引用为两条独立证据**，也**禁止**把"C 与 PPMI 均支持"表述为"多重证据"。

同理：`z / q1 / q12 / q123` 是**同一条链上的四个阶段**，不是四个独立数据集。

## 3. 相似度定义（唯一）

```
cos(a, b) = <a, b> / (||a||₂ · ||b||₂)
实现：先各行 L2 归一化（clamp min=1e-9，保留零向量），再做内积。
```

| 项 | 冻结值 |
|:--|:--|
| 方向 | **降序**（相似度越大 = 越近） |
| 排除自身 | **强制**：`i ∉ N_K(i)`，恒成立 |
| 候选集合 | **全库 `N` 个 item**（不做 degree 限制、不做分块过滤）；仅受 §5 的 item universe 约束 |
| 零向量 | `cos(0, x) = 0`（由 clamp 保证，**不产生 NaN**）；其排序含义见 §5 |
| 禁止 | ❌ **欧氏距离**。既有 `tools/analyze_emb_orthogonality.py:33-34` 的 `np.linalg.norm(vecs - vecs[idx])` 是欧氏距离，仅在**已归一化**空间与余弦同序，**不得**用于 `z_raw` / 未归一化 `Bh`。P1.2 统一改为余弦。 |

## 4. Top-K 与**并列**规则（冻结）

### 4.1 排序键（**两级，不允许第三级**）

| 优先级 | 键 | 方向 |
|:--:|:--|:--|
| 第一 | 余弦相似度 `cos(i, j)` | **降序** |
| 第二（并列时） | **canonical item index**（`item_id_to_row` 给出的 0-based 行号） | **升序** |

> **强制**：**禁止**使用共现频次（或任何行为/内容侧的统计量）作为次级键 ——
> 否则**被评估的排序会被评估对象本身影响**，指标失去意义。
> 实现要求：`np.lexsort` 或 `argsort(kind="stable")`；**禁止**使用默认 `np.argsort`（quicksort，非稳定）。
> ⚠ 既有 `tools/analyze_emb_orthogonality.py:36` 正是默认 `np.argsort`，P1.2 必须替换。

### 4.2 必须伴随报告的并列诊断

| 量 | 定义 | 报告粒度 |
|:--|:--|:--|
| **边界并列比例** | `tie_share@K = mean_i [ #{ j ≠ i : cos(i,j) == cos(i, n_K(i)) } ] / K`，其中 `n_K(i)` 是第 K 名邻居 | 每个 (空间, 数据集, K) |
| **表示塌缩率** | `collapse = 1 − |unique(rows)| / N` | 每个 (空间, 数据集) |
| **逐层碰撞率** | 复用 `tools/checkpoint_trajectory_probe.py:98-109` 的 `prefix{k}_collision_rate`、`full_sid_collision_rate` | 每个 (变体, 数据集) |

> **依据 + P1.1 实测回填（2026-10-14）**：`q1 / q12 / q123` 由**精确码本查表**重建
> （`tools/sid_per_layer_diagnostic.py:65-71`），不同 item 可得到**逐位完全相同**的向量
> ⇒ 组内 `cos ≡ 1.0`。**但并列规模在三个量化阶段差异极大，不得笼统陈述**：
>
> | 空间 | `collapse = 1 − \|unique(rows)\|/N`（Sport / Toys / Beauty） | 最大同值组 |
> |:--|:--|:--|
> | `q1` | **0.9864 / 0.9826 / 0.9831** | 428 / 210 / 198 |
> | `q12` | **0.2879 / 0.2464 / 0.2532** | 18 / 35 / 35 |
> | `q123` | **0.0000 / 0.0008 / 0.0005** | 1 / 3 / 2 |
> | `z_raw` / `z_norm` | 0.0000（三集） | 1 |
> | `input896` / `content768` | 0.0000（三集，Toys `content768` 有 1 组重复行） | 1 / 2 |
>
> - `q1` 的塌缩是**结构性**的：`q1 = cb₀[codes[:,0]]` 完全由第 0 层码决定，该层实际仅使用
>   249 / 207 / 204 个码（≤ 256），故 `|unique(q1)|` 的上界就是第 0 层码用量。
> - `q123` **几乎不塌缩**：codegen 的碰撞消解循环保证最终 3 列码唯一
>   （`rqvae/generate_sid_codes_param.py:83-110`），故全量量化表示的完全同值向量**很少**。
>   ⇒ §4.3 敏感性检查在不同阶段会遇到**性质不同**的并列，必须**逐 (空间对, K) 判定**，不可外推。
> - **纪律**：`q1` 的高塌缩是**已测事实**，**不得**据此推断"行为结构在第 1 层丢失"——
>   那是 §7-B 的邻域指标要回答的问题。本表只是**并列规模的先验**，不是结构丢失的证据。

### 4.3 并列敏感性检查（**强制**）

对每个 `(空间对, K)`：

- 将次级键方向由 **index 升序** 翻转为 **降序**，重算 §7 的全部邻域指标；
- 若任一指标变动 **> 0.005**，该格标记为 **`tie-sensitive`**，**不得据其下结论**，必须在报告中单独列出；
- 若变动 ≤ 0.005，标记 `tie-stable`，可进入结论。

## 5. 零向量 / 冷启动物品策略（**两套 item universe**）

### 5.1 成因（已核实）

冷启动物品在 `rqvae/build_transition_graph.py:291-294` 被**显式置零**：
`if i not in seen_items: behavior_emb[i] = 0.0`。⇒ 零向量 ⇔ **该 item 未出现在构建行为图所读到的序列集合中**。
另一种情形（出现在序列中但在窗口内无共现伙伴）也会因 PPMI 行为全零而得到零向量。

> **待验证**：`||behavior_emb[i]||₂ == 0` 的集合 与 `deg == 0`（E 图度为零）的集合**是否一致**。
> 二者定义不同（前者来自 `seen_items`，后者来自图）。协议据此**采用向量范数**作为判据（可实测、与主分析同口径），
> 并要求 P1 报告两个集合的差集大小。

### 5.2 冻结规则（**按分析族分开**）

| 分析族 | item universe | 规则 |
|:--|:--|:--|
| **(甲) 行为结构保持主分析**<br>即 `Bh → {z, q1, q12, q123}` | **`U_beh = { i : ‖Bh[i]‖₂ > 0 }`** | **剔除**零行为向量 item。**必须单独报告**：`n_zero`、`zero_ratio = n_zero/N`、`coverage = |U_beh|/N` |
| **(乙) 连续→量化邻域保持分析**<br>即 `z → {q1, q12, q123}`、`X → z` | **`U_cont = 全部 N`** | **不因行为向量为零而额外剔除**任何 item（该分析不涉及行为向量） |

### 5.3 补充分析（可选，**必须单独报告**）

若要把零向量纳入 (甲)，必须① 单独成篇成表，**不得**并入主表；② 显式声明：

> 零向量互之间、以及与任意向量的余弦恒为 **0**，其邻居排序**完全由 §4.1 的次级键（canonical index）决定** ——
> 这是**人为并列**，**不是**真实行为关系。此类结果**不得**解释为"行为结构被保留/丢失"。

### 5.4 既有代码的支持情况（供 P1.1/P1.2 参考）

- 主判据负采样**已排除**零度 item：`tools/behavior_structure_probe.py:213` `bucket_of[deg == 0] = -1`（冷启动物品不参与 degmatch 分桶）。
- 但**没有任何**邻域指标做零向量剔除 —— 这是 P1.2 必须新增的。
- `normalize_rows` 用 `clamp(min=1e-9)` **保留**零向量（`tools/sid_per_layer_diagnostic.py:74-77`），不产生 NaN。

## 6. **两类诊断必须分开**（本协议的核心区分）

| | **类 A：物品对相似度变化**（pair-level） | **类 B：Top-K 邻域保持**（set-level） |
|:--|:--|:--|
| 问题 | "这一对 item 在这一阶段**还像不像**？" | "这个 item 的**邻居们**还是不是同一批？" |
| 对象 | **固定物品对集合**（正/负样本） | **每个 item 的 Top-K 集合** |
| 度量 | `cos` 的均值/中位数/Δ、**edge AUC** | `Neighbor Recall@K`、标准 `Jaccard@K`、`Top-K overlap@K` |
| 现有实现 | **全部已有**（`behavior_structure_probe.py` 等 8 个探针） | **全部缺失**（零实现） |

> **纪律**：**AUC 高不蕴含 Recall@K 高**（秩保持 ≠ 集合保持），反之亦然。
> 两者**必须并列报告**；**禁止**用其中一个替代另一个，**禁止**把 AUC 称为"邻域保持"或 "BSR"。

## 7. 指标定义（冻结）

设 `N_K^A(i)` 为空间 A 中 item `i` 的 Top-K 邻居（按 §3–§4，已排除自身），`U` 为该分析的 item universe。

### 7-A 类 A（保留既有主判据，不新增）

- **edge AUC**（主判据）：`AUC = P( cos(正样本对) > cos(负样本对) )`，负样本取 **degmatch**；
  `uniform` 负样本仅作参照。实现沿用 `tools/behavior_structure_probe.py` 的
  `cos_sim` / `auc_of` / `sample_neg_degmatch`。

### 7-B 类 B（**全部为新增实现**）

| 指标 | 定义 | 备注 |
|:--|:--|:--|
| **Neighbor Recall@K** | `Recall@K(A→B) = (1/\|U\|) Σ_{i∈U} \|N_K^A(i) ∩ N_K^B(i)\| / K` | 主指标之一 |
| **标准 Jaccard@K** | `Jaccard@K(A→B) = (1/\|U\|) Σ_{i∈U} \|N_K^A(i) ∩ N_K^B(i)\| / \|N_K^A(i) ∪ N_K^B(i)\|` | **主指标之一**；两侧等 K 时 = `overlap / (2K − overlap)` |
| **Top-K overlap@K** | `Overlap@K(A→B) = (1/\|U\|) Σ_i \|A_i ∩ B_i\| / K` | **保留为第三个独立量**，专供与历史数字对齐；**禁止称其为 Jaccard** |

> **明确更正**：`tools/analyze_emb_orthogonality.py:86` 的 `jaccard = overlap / k` **不是** Jaccard，
> 而是 `Overlap@K`。既有文档中任何以"Jaccard"称呼该量的表述**一律作废**。

### 7-C 需要跑的空间对（预注册）

| 组 | 空间对 | universe |
|:--|:--|:--|
| **量化前后保持** | `z_norm→q1`、`z_norm→q12`、`z_norm→q123` | `U_cont` |
| **行为结构保持** | `Bh→z_norm`、`Bh→q1`、`Bh→q12`、`Bh→q123` | `U_beh` |
| **上游参照** | `Ct→Bh`、`X→z_norm`、`SID`（离散口径另列） | 各自适用 universe |

## 8. K 值、共同锚点、抽样与对齐

### 8.1 K 值（冻结）

**K ∈ {5, 10, 20, 50, 100}；主 K = 20。**

理由：① 与 T5 评测的 `topk_list` 对齐，便于与 `NDCG@20 / Recall@20` 做同层对照；
② 20 与既有 `tools/analyze_emb_orthogonality.py:74` 的 `k = 20` 一致，保留历史可比性。
约束：**K < min(|U|)**；报告必须给出 K 曲线而非单点。

> ⚠ **不得混用**仓库里另外两类 "K"：`TOPK_POS = 1000` 是**高频边条数**（`behavior_structure_probe.py`），
> eval 的 `topk_list` 是**推荐列表长度**。三者语义不同。

### 8.2 共同锚点（**强制**）

- 所有空间对必须使用**同一个 item 顺序**（`item_id_to_row`）与**同一个 query 子集**；
- **同一 (数据集, 变体, 种子) 的所有空间共享一次对齐**，不得各脚本各对齐一次；
- 类 A 与类 B 在同一数据集内使用**同一张 E 图**（同一份正负样本），使两类诊断可对读。

### 8.3 抽样规则

- **query 集合**：默认**全量**（`|U|` 全部 item），相似度矩阵**分块计算**（建议 chunk = 512 行），避免 `N×N` 全物化。
- 若成本不允许（如 content 768d × 大 N），回落为**固定种子抽样** `n_query = min(2000, |U|)`、`seed = 2024`，并在报告中显式标注"抽样口径"。
- ⚠ **不得**沿用 `tools/analyze_emb_orthogonality.py:76` 的 `random.sample(...)` —— 该脚本**未设随机种子**（`import random` 后无 `seed()` 调用，实测第 76 / 116 / 177 / 178 行均为无种子随机），**不可复现**。
- **候选集合**：全库 `N`（§3），不是抽样集合。抽样只作用于 **query 端**。

## 11. 评估纪律（**强制并列报告项**）

**U2 — 有差异，且差异已被完全解释。** 最终 codes（npy 落盘值）与 `use_sk=False` 前向 argmin
索引在 **209 / 226 / 235 行**（1.14% / 1.90% / 1.94%）不同，**全部落在第 2 层**：

| 数据集 | 首轮唯一码 | 首轮碰撞率 | 最终碰撞率 | 最终码第 4 列非零 | 索引≠前向 | 逐层 | max\|Δx_q\|（码一致行） | max\|Δx_q\|（改写行） |
|:--|--:|--:|--:|--:|--:|:--|--:|--:|
| Sport | 18249 | 0.0059 | 0.0000 | 0 | 209 | [0, 0, 209] | 4.77e-07 | 1.328 |
| Toys | 11805 | 0.0100 | 0.0008 | 9 | 226 | [0, 0, 226] | 4.77e-07 | 1.117 |
| Beauty | 11970 | 0.0108 | 0.0005 | 6 | 235 | [0, 0, 235] | 4.77e-07 | 1.249 |

- **成因**：codegen 首轮为纯 argmin，产生碰撞的组被 `use_sk=True` 重解码改写，而只有第 2 层
  `sk_epsilon > 0`（各层 `sk_epsilons=[0,0,0.003]`，且 `generate_sid_codes_param.py` 对
  `vq_layers[:-1]` 显式置 0）⇒ **差异集合 ≡ 索引差异集合，零残差**。
- **裁决（维持 §2.1 原规则）**：`q1 / q12 / q123` 的唯一真值 = `rebuild_xq_partial(codes, cb, L)`。
  `use_sk=False` 的前向输出**不是** SID 的量化表示，也不被任何下游使用（T5 读的是 codes）。
- ⚠ **表述纪律**：不得写"`xq[full]` = 模型量化输出"——对上述 1–2% 的行不成立；
  正确表述是"`xq[full]` = 由 SID 码经码本精确重建的量化表示"。
- **附带事实**：codes 第 4 列（碰撞消解序号）Sport 全 0、Toys 9 个非零、Beauty 6 个非零。

**P1.1 顺带实测的对齐事实（A7 经验证）**：三数据集的 `codes` / `fused` / `item_emb_768d` **行序
逐位一致**（若错位则"索引≠前向"的行数会接近 N，实测仅 1.1%–1.9%）；`ckpt.args.data_path` 与
`FUSED_896D[variant]` 指向**同一实体**（Beauty 的 `fused_item_emb_768d.parquet` 是软链）；
